# Task Reset Companion

A tiny single-page app for task initiation support (ADHD/anxiety-friendly).

## What it includes
- 8 non-gamified concept ideas for a motivation/support app.
- State-based strategy cards (avoidance, overwhelm, shame, initiation difficulty, anxiety, re-entry).
- Self-talk prompts.
- Paired YouTube channel links for further support.
- Tiny first action generator.
- 5-minute permission timer.

## Run
Open `index.html` in your browser.
